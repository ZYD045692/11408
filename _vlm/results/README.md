# VLM 鉴定结果说明书

> 这份说明告诉你看什么、怎么看。**一句话**：我们用小模型（Qwen3.5-4B，硅基流动免费额度）把 8 本书的 OCR markdown 和原书扫描页逐一核对，模型的"观察记录"全部放在这里。它只说"看到了什么差异"，不下结论——**是否算缺陷由人来裁定**。

## 为什么有这个目录

8 本书的 markdown 由扫描版 PDF 经 OCR + 程序清洗而来。清洗可能引入两类问题：
1. **把本该是文字的内容留在了图片里**（比如一整段文字、公式被截图保存，没法搜索/复制）
2. **内容丢失**（题目缺选项、答案解析被截断、正文段落漏了）

人眼逐页核对 8 本书不现实，所以用多模态小模型批量"看图对稿"，把可疑之处全部记录下来。

## 五个任务 & 五个目录

| 目录 | 核对什么 | 观察单元 | 主要看什么 |
|---|---|---|---|
| `task1_images/` | 书里提取出的每张插图（2288 张）是不是正文内容 | 1 张图 = 1 行 | B 类、D 类（见下） |
| `task3q/` | 习题节的**题目**是否完整 | 1 道题 = 1 行 | 有 ❌ 的行 |
| `task3a/` | 习题节的**答案与解析**是否完整 | 1 道题 = 1 行 | 有 ❌ 的行 |
| `task2_sections/` | 正文小节（### X.Y.Z）与书页逐块对照 | 1 个内容块 = 1 行 | 🟡部分 / ❌无 |
| `task3_match/` | **题↔答对应核查**（纯文本比对，不调模型） | 1 个单元 = 1 行 | 缺答/缺题列非空的行 |

**task3_match 说明**：不经模型，直接比对 markdown 里"题目集合"与"答案集合"的题号。缺答=有题没答案（疑似解析丢失或并进他题）；缺题=有答案没题（疑似题目丢失——1000题已用此发现 14 道书上存在但试题册稿里丢失的题）。408 按小节号 X.Y 配对，30讲按讲配对，1000题按 试题册↔解析册 章名模糊配对（表内标注相似度）。

每个目录下：`书名.jsonl` 是机器账（原始数据），**`书名.md` 是给人看的观察表**（由 jsonl 自动生成，随时可重建）。

## 任务1 观察表怎么读（插图鉴定）

每行一张图：图名 | 缩略图 | cat | sub | 描述 | raw

- **cat（大类）**：
  - `A` = **正文插图**——承载本科目知识内容的图（坐标图、几何图形、结构图、流程图、思维导图…），正常
  - `B` = **内容型图片**——本该排版成文字/公式的正文内容被截成了图片，**重点排查对象**
  - `C` = 模型无法判断
  - `D` = **非正文图片**——与知识无关的装饰/功能性图片（小图标、警示标志、二维码、Logo、水印、广告、封面元素、装饰插画、空白损坏等），**本流水线最想筛出的对象**
  - `PARSE_FAIL` / `CALL_FAIL` = 模型返回解析失败 / API 调用失败（技术异常，不是书的问题）
- **sub（细类）**：B 类填 文字段落/公式/表格/目录页/整页书页/图文混合/二维码或广告/空白或损坏/其他；D 类填 图标/警示标志/二维码或广告/装饰插画/Logo或水印/封面元素/空白或损坏/其他；显示 `·` 表示无细类
- **描述**：模型对图片内容的一句话客观描述（分类出错时也能据此人工判断）
- **raw**：模型返回的原文，用于追溯复核

## 任务3 观察表怎么读（题目 Q / 答案 A）

每行一道题，标志位 ✅=正常 / ❌=模型观察到缺失 / ·=不适用（书上本来就没有）：

**Q（题目）**：`present`=题在不在 · `stem`=题干完整 · `options`=选项齐全（书上ABCD而稿里缺了就是❌）· `subq`=子问齐全 · `figure`=题说"如图"时稿里有图占位
**A（答案）**：`present`=答案在不在 · `letter`=答案字母在不在（缺失=解析可能并进了上一题）· `analysis`=解析完整（中间断句=❌）

- **note**：模型说明的具体差异（空=无差异）
- **evidence**：模型从书页引用的原文证据。**没有 evidence 的观察不可信**，不进后续裁定
- **raw**：标在每节第一行（一次调用覆盖整节，原文只有一段）
- 表头注明"异常行 N"：该书的 CALL_FAIL/NO_BOOKMARK（书签缺失）/SKIP 节数，明细在 jsonl
- **数学四本书的"节"（sec 列）**：30讲=讲（如"第2讲 数列极限"）；1000题=篇/章（如"基础篇/第9章 …"）；测试卷=综合篇/测试卷X/题型。页对齐方式：数学 PDF 无书签，用 Umi-OCR 全文索引定位（题号行首匹配+单调游标），408 用 PDF 书签

## 任务2 观察表怎么读（小节对照）

模型按书上顺序列出该节内容块（正文/例题/图表/公式块…），逐块标注在 markdown 里 `✅有 / 🟡部分 / ❌无`。广告、二维码、页眉页脚是**故意删除**的，不算缺失。

## 数据可信吗

- 上线前过了**校准**（`calibration/`）：6 张已知分类的图 6/6 正确；程序注入"删选项/删答案字母"的造假缺陷，模型 3/3 全部指出
- 但小模型仍会犯错（尤其 A/B 边界、"像不像"的主观题），所以**所有标 ❌/B 的行都要人工对照原书 PDF 终审**，本目录只提供"哪里值得看"
- `SUMMARY.md` 是跑完后的对账汇总（行数对账、异常计数、抽查样本）

## 技术背景（一眼版）

- 模型：硅基流动 Qwen3.5-4B 多模态，限速 70k TPM；脚本在 `_vlm/scripts/`
- 页对齐：408 四本用 PDF 书签定位小节页范围（前后各带 1 页灰标上下文）；数学 PDF 无书签，用 Umi-OCR（本地 127.0.0.1:1224）建全书全文索引，按"章标题+行首题号+单调游标"定位每题页码
- 断点续跑：每行追加写盘，中断重跑自动跳过已完成项；原始返回全文留档（raw 字段），重处理不必重调 API
