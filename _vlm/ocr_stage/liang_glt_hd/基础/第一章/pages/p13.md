## 可胖瑛

（1）若出现几个事件至少一个发生时,表示这几个事件的和事件.比如事件 A, B, C 至少一个发生,可表示为  $ A + B + C $.

(2) 隐含的包含关系:  $ A \subset A + B $;  $ B \subset A + B $.

（4） $ A $ 和  $ B $ 的积事件: 称事件  $ A \cap B = \{x \mid x \in A \text{ 且 } x \in B\} $ 为  $ A $ 和  $ B $ 的积事件. 它表示  $ A, B $ 两个事件同时发生时事件  $ A \cap B $ 发生,  $ A \cap B $ 也记为  $ AB $.

类似地,称 $ \bigcap_{k=1}^{n}A_{k} $为n个事件 $ A_{1},A_{2},\cdots,A_{n} $的积事件.

## 良哥解读

隐含的包含关系:  $ AB \subset A $;  $ AB \subset B $.

(5) A 和 B 的差事件: 事件  $ A - B = \{x \mid x \in A \text{ 且 } x \notin B\} $ 称为事件 A 和 B 的差事件. 它表示 A 发生且 B 不发生时事件 A - B 发生. A - B 也可记为  $ \overline{AB} $.

(6)互斥事件(互不相容): 当  $ AB = \varnothing $ 时, 称事件 A 和 B 互不相容(或互斥). 它表示事件 A 和 B 不能同时发生.

(7)对立事件(逆事件):若 $ A\cup B=\Omega $且 $ A\cap B=\varnothing $,则称A和B互为逆事件,也称互为对立事件.A的对立事件记为 $ \overline{A} $.

## 良哥解读

互斥事件与对立事件的关系:两个事件对立则一定互斥,但互斥不一定对立.

（8）完全（备）事件组：若事件组  $ A_{1}, A_{2}, \cdots, A_{n} $ 满足：

 $ A_{1}\cup A_{2}\cup\cdots\cup A_{n}=\Omega,A_{i}A_{j}=\emptyset,1\leq i\neq j\leq n $，则称事件 $ A_{1},A_{2},\cdots,A_{n} $是一个完全（备）事件组，也称为样本空间的一个划分.

(1) A, B, C 中只有 A 发生；(2) A, B 都发生，而 C 不发生；

(3) A, B, C 同时发生；(4) A, B, C 至少有一个发生；

(5) A, B, C 至少有两个发生; (6) A, B, C 只有一个发生;

(7) A, B, C 不多于一个发生.

(3)ABC;

(5) A, B, C 至少有两个发生, 表示 A, B, C 中两个事件发生的和事件, 即

 $$ AB+AC+BC； $$
