【例 1.23】设  $ A, B $ 为随机事件，若  $ 0 < P(A) < 1, 0 < P(B) < 1 $，则  $ P(A \mid B) > P(A \mid \overline{B}) $ 的充分必要条件是 ( )。

(A)  $ P(B \mid A) > P(B \mid \overline{A}) $

(B)  $ P(B \mid A) < P(B \mid \overline{A}) $

(C)  $ P(\overline{B} \mid A) > P(B \mid \overline{A}) $

(D)  $ P(\overline{B} \mid A) < P(B \mid \overline{A}) $

【解析】因  $ P(A \mid B) > P(A \mid \bar{B}) $ 等价于  $ \frac{P(AB)}{P(B)} > \frac{P(A\overline{B})}{P(\overline{B})} $，又  $ P(A\overline{B}) = P(A\overline{B}) - P(A\overline{B}), P(\overline{B}) = 1 - P(B) $

可得  $ P(A \mid B) > P(A \mid \overline{B}) $ 等价于  $ P(AB) > P(A)P(B) $.

对于(A)选项:因  $ P(B \mid A) > P(B \mid \overline{A}) $ 等价于  $ \frac{P(AB)}{P(A)} > \frac{P(B \overline{A})}{P(A)} $，又  $ P(B\overline{A}) = P(B) - P(AB) $， $ P(\overline{A}) = 1 - P(A) $.

整理得  $ P(B \mid A) > P(B \mid \overline{A}) $ 等价于  $ P(AB) > P(A)P(B) $. 故应选(A).

【例1.24】设A,B,C为随机事件，A与B相互独立， $ P(C)=1 $。则可能不相互独立的事件组为（）。

(B) A, B, A - C

(C) A, B, AC

(D) A, B,  $ \overline{A} $C

 $$ P(A\cup C)=1,P(A-C)=0,P(\overline{A}\overline{C})=0. $$

故 A 与 AC 不独立，因此 (C) 中的事件组 A, B, AC 不相互独立.

【例1.25】设 A, B, C 三个事件两两独立，则 A, B, C 相互独立的充分必要条件是( )。

(A) A 与 BC 独立 (B) AB 与 AUC 独立

(C) AB 与 AC 独立 (D) A∪B 与 AUC 独立

【解析】A,B,C 相互独立的充要条件是 A,B,C 事件两两独立且满足  $ P(ABC) = P(A)P(B)P(C) $。因 A,B,C 两两独立，故只需验证  $ P(ABC) = P(A)P(B)P(C) $ 即可。

对于(A)选项:若 A 与 BC 独立,则  $ P(ABC) = P(A)P(BC) = P(A)P(B)P(C) $.

故应选(A).
