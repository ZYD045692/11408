$n=1,2,\cdots$,则对于任意实数 $x$,有 $\lim_{n\to\infty}P\left\{\sum_{k=1}^{n}X_k-n\mu\over\sqrt{n}\sigma\leq x\right\}=\Phi(x)$.

## 二、 棣莫弗-拉普拉斯中心极限定理

设随机变量  $ X_{n} $ 服从参数为 n, p 的二项分布, 即  $ X_{n} \sim B(n, p), 0 < p < 1, n = 1, 2, \cdots $, 则对于任意实数 x, 有  $ \lim_{n \to \infty} P\left\{\frac{X_{n} - np}{\sqrt{np(1 - p)}} \leq x\right\} = \Phi(x) $.

## 考点及方法小结

中心极限定理的两个考查方向：

(1) 考条件: 随机变量序列  $ X_{1}, X_{2}, \cdots, X_{n}, \cdots $, 需满足相互独立, 服从相同的分布, 且  $ E(X_{i}) $ 和  $ D(X_{i}) $ 均存在.

(2) 考结论: 足够多的随机变量的和  $ \sum_{k=1}^{n} X_{k} $ 近似服从正态分布, 将其标准化后按标准正态分布解决.

## <精选例题>

【例 5.7】设  $ X_{1}, X_{2}, \cdots, X_{n} $ 是总体 X 的简单随机样本，且  $ E(X) = 5, D(X) = 25, \overline{X} = \frac{1}{n} \sum_{i=1}^{n} X_{i} $ 为样本均值，若要使概率  $ P\left\{\overline{X} \leq 6\right\} $ 不小于 0.95，已知  $ \Phi(1.64) = 0.95 $，用中心极限定理计算，样本容量 n 至少为 ___.

【解析】因  $ E(\sum_{i=1}^{n}X_{i})=5n, D(\sum_{i=1}^{n}X_{i})=\sum_{i=1}^{n}D(X_{i})=25n $，故由中心极限定理知， $ \sum_{i=1}^{n}X_{i}\sim N(5n,25n) $。又  $ P\left\{\overline{X}\leq6\right\}=P\left\{\sum_{i=1}^{n}X_{i}\leq6n\right\}\geq0.95 $，故有

 $$ \begin{aligned}P\left\{\sum_{i=1}^{n}X_{i}\leq6n\right\}&=P\left\{\frac{\sum_{i=1}^{n}X_{i}-5n}{5\sqrt{n}}\leq\frac{6n-5n}{5\sqrt{n}}\right\}\\&\approx\Phi\left(\frac{6n-5n}{5\sqrt{n}}\right)=\Phi\left(\frac{\sqrt{n}}{5}\right)\geq0.95=\Phi(1.64),\end{aligned} $$ 

因此  $ \frac{\sqrt{n}}{5} \geq 1.64 $，解得  $ n \geq 67.24 $，故 n 至少为 68.
