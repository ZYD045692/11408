## <精选例题>

【例2.1】假设  $ F(x) $ 是随机变量 X 的分布函数，则不正确的是（）.

(A) 如果  $ F(a)=0 $, 则当  $ x \leq a $ 时, 有  $ F(x)=0 $

(B) 如果  $ F(a)=1 $, 则当  $ x \geq a $ 时, 有  $ F(x)=1 $

(C) 如果  $ F(a)=\frac{1}{2} $, 则  $ P\{X \leq a\} = \frac{1}{2} $

(D) 如果  $ F(a) = \frac{1}{2} $, 则  $ P\{X \geq a\} = \frac{1}{2} $

【解析】对于(A)选项，因为 $ F(a)=0 $，即 $ P\{X \leq a\} = 0 $，而当 $ x \leq a $时， $ \{X \leq x\} \subset \{X \leq a\} $，故 $ P\{X \leq x\} = 0 $，即 $ F(x) = 0 $，从而(A)正确。

对于(B)选项，因为 $ F(a)=1 $，即 $ P\{X \leq a\} = 1 $，而当 $ x \geq a $时， $ \{X \leq a\} \subset \{X \leq x\} $，故 $ P\{X \leq x\} = 1 $，即 $ F(x)=1 $，从而(B)正确。

对于(C)选项,因 $ F(a)=P\{X\leq a\} $,故(C)正确,从而应选(D).

事实上对于(D)选项,由 $ F(a)=P\{X\leq a\}=\frac{1}{2} $,有 $ P\{X\geq a\}=1-P\{X<a\}=1-F(a-0) $,但分布函数不一定左连续,即 $ F(a-0) $与 $ F(a) $不一定相等,从而 $ P\{X\geq a\}=\frac{1}{2} $不一定成立.

【例 2.2】设  $ F_{1}(x) $ 与  $ F_{2}(x) $ 为随机变量  $ X_{1} $ 与  $ X_{2} $ 的分布函数. 若  $ F(x)=aF_{1}(x)-bF_{2}(x) $ 是某一变量的分布函数, 在下列给定的各组数值中应取().

(A)  $ a = \frac{3}{5}, b = -\frac{2}{5} $

(B)  $ a = \frac{3}{5}, b = \frac{2}{3} $

(C)  $ a = -\frac{1}{2}, b = \frac{3}{2} $

(D)  $ a = \frac{1}{2}, b = -\frac{3}{2} $

【解析】若  $ F(x) $ 为分布函数，则  $ \lim_{x\to+\infty}F(x)=1 $，故  $ \lim_{x\to+\infty}\left[aF_{1}(x)-bF_{2}(x)\right]=a-b=1 $，由于四个选项中只有（A）满足此条件。故应选（A）。

## 良哥解读

设  $ F_{1}(x) $ 与  $ F_{2}(x) $ 均为分布函数,  $ F(x)=aF_{1}(x)+bF_{2}(x) $, 若  $ a \geqslant 0, b \geqslant 0 $, 且  $ a+b=1 $, 则  $ F(x) $ 一定为某个随机变量的分布函数.

【例2.3】设随机变量X的分布函数为 $ F(x) $，则下列可作为某个随机变量分布函数的是( )。(A) $ F(ax) $ (B) $ F(x^{2}+1) $ (C) $ F(x^{3}-1) $ (D) $ F(|x|) $

【解析】对于(A)选项, 当 a<0 时,  $ \lim_{x\to-\infty}F(ax)=1 $, 故  $ F(ax) $ 不一定是分布函数. 对于(B)选项, 因  $ \lim_{x\to-\infty}F(x^{2}+1)=1 $, 故  $ F(x^{2}+1) $ 一定不是分布函数.

对于(C)选项, 因  $ 0 \leq F(x^{3}-1) \leq 1 $,  $ \lim_{x \to -\infty} F(x^{3}-1) = 0 $,  $ \lim_{x \to +\infty} F(x^{3}-1) = 1 $, 且满足单调不减性和右连续性, 故  $ F(x^{3}-1) $ 一定是分布函数, 应选(C).

对于(D)选项, 因  $ \lim_{x\to-\infty}F(|x|)=1 $, 故  $ F(|x|) $ 一定不是分布函数.
