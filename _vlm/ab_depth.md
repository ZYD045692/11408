

【一句话】
连续存储换取 O(1) 随机访问，代价是插入删除需成批移动元素 O(n)。

【要点】
考点 1：存储结构定义
**核心结论**：逻辑相邻即物理相邻，支持随机存取，分静态与动态分配。
**代码**：
```c
// 静态
typedef struct{ ElemType data[MaxSize]; int length; } SqList;
// 动态
typedef struct{ ElemType *data; int MaxSize, length; } SeqList;
```
**考试怎么用/易错提醒**：位序 $i$ 从 1 开始，数组下标为 $i-1$；动态分配需 `malloc` 或 `new`；动态分配仍属顺序存储，非链式。

考点 2：插入操作
**核心结论**：后移元素腾位置，平均移动 $n/2$ 次，时间复杂度 $O(n)$。
**代码**：
```c
for (int j=L.length; j>=i; j--) L.data[j]=L.data[j-1];
L.data[i-1]=e; L.length++;
```
**考试怎么用/易错提醒**：插入位置 $i$ 范围 $1 \le i \le n+1$；循环从表尾 $n$ 向前至 $i$；最好情况（尾插）$O(1)$。

考点 3：删除操作
**核心结论**：前移元素补空缺，平均移动 $(n-1)/2$ 次，时间复杂度 $O(n)$。
**代码**：
```c
e=L.data[i-1];
for (int j=i; j<L.length; j++) L.data[j-1]=L.data[j];
L.length--;
```
**考试怎么用/易错提醒**：删除位置 $i$ 范围 $1 \le i \le n$；循环从 $i$ 向后至 $n-1$；最好情况（尾删）$O(1)$。

考点 4：时间复杂度分析
**核心结论**：按序号访问 $O(1)$，按值查找/插入/删除平均 $O(n)$。
**公式**：
插入平均移动次数：$$\frac{n}{2}$$
删除平均移动次数：$$\frac{n-1}{2}$$
按值查找平均比较次数：$$\frac{n+1}{2}$$
**考试怎么用/易错提醒**：2023 年考过复杂度分析；注意区分最好、最坏与平均情况。

【易混】
| 对比项 | 插入操作 | 删除操作 |
| :--- | :--- | :--- |
| 移动方向 | 后移 (从后往前) | 前移 (从前往后) |
| 循环起点 | 表尾 $L.length$ | 被删位置 $i$ |
| 循环终点 | 插入位置 $i$ | 表尾 $L.length-1$ |
| 下标转换 | 插入 $i-1$ | 删除 $i-1$ |
| 合法范围 | $1 \le i \le n+1$ | $1 \le i \le n$ |

【闪卡】
- 顺序表随机访问时间复杂度::O(1)
- 顺序表插入平均移动次数::n/2
- 顺序表删除平均移动次数::(n-1)/2
- 静态顺序表数组定义::ElemType data[MaxSize]
- 动态顺序表指针定义::ElemType *data
- 插入位置 i 合法范围::1 ≤ i ≤ n+1
- 删除位置 i 合法范围::1 ≤ i ≤ n
- 按值查找返回 0 含义::未找到元素
